### Hey, I'm Neel! (^^)/

Welcome to my little corner of the internet. If you're here, you probably like looking at code, checking out how things are built, or maybe we just crossed paths somewhere on the web. Either way—pull up a chair.

I'm a **Full-Stack Web Developer**, which is really just the official way of saying I love taking a weird, half-baked idea on a napkin and figuring out how to make it live and breathe on a screen. I learned web development from the ground up—writing raw DOM manipulation, state logic, and data structures in pure JavaScript before ever touching a framework—because I'm endlessly curious about how things actually work under the hood.

I genuinely believe that **imperfect perfection creates warmth**. Software doesn't have to feel cold or robotic. At its best, code is a craft made by humans for humans—and a little bit of personality in what we build goes a long way.

### ╭── How My Brain Works

- **Fundamentals over magic.** Because I built things with vanilla HTML, CSS, and JavaScript first, frameworks like React don't feel like a black box to me—I always want to know *why* a re-render happens or how the DOM is actually updating.
- **Deep work & async flow.** I skip the noise of endless social media feeds so I can sink into long, uninterrupted blocks of building and thinking. Just like good non-blocking code, I work best asynchronously—thoughtful commits, clear documentation, and conversations that don't demand an instant ping back.
- **The joy of the rabbit hole.** Whether it's writing Jest tests to break my own logic, refactoring spaghetti code into clean factory functions, or tweaking my Linux setup until the keybindings feel just right, I genuinely enjoy the process as much as the final `git push`.
